κ (Kappa) — The Measure

The Question

Before we can find optimal balance, we need to measure it. How chaotic or ordered is a system right now?

The Answer: κ (Kappa)

κ is a normalized scale from 0 to 1:

κ = 0 Pure order. Frozen. Crystalline. No creativity possible.
κ = 0.5 Half and half. Unstable—will drift one way or another.
κ = 0.618 The sweet spot. 62% chaos, 38% order. Optimal.
κ = 1 Pure chaos. Noise. No structure. System fragments.

This Leads To...

We now have a way to measure balance. But why 0.618? What's special about that number?

The answer lies in φ (phi), the golden ratio. 0.618 is exactly 1/φ.
