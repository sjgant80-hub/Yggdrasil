LESSON 2 — TASK

How to Measure Balance

The Task

We need a number that measures chaos vs order.

That number is κ (kappa) = normalized entropy.

The Formula

κ = H(S) / log₂(n)
κ = entropy / max_possible_entropy

Result: a number between 0 and 1.

What κ Values Mean

κ = 0.0Frozen, stuck
κ = 0.382Safe zone minimum
κ = 0.618Optimal flow
κ = 0.809Safe zone maximum
κ = 1.0Pure noise
