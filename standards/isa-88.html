STANDARD 2 — BEHAVIOR

ISA-88: Procedures

The Purpose

Systems need repeatable behavior.

ISA-88 defines how procedures execute as state machines.

Phase State Machine

IDLE → RUNNING → COMPLETE
       ↓ HOLD
    HOLDING → HELD → RESTART
       ↓ STOP
   STOPPING → STOPPED
       ↓ ABORT
   ABORTING → ABORTED

Every phase follows these states. Predictable. Reliable.

Connection to κ

State machines prevent chaotic behavior.

They constrain κ by limiting possible transitions. Order without rigidity.
